📊 诊断步骤

  1. 网络连接检查： 验证能否连接到 API 服务
  2. 模型加载检查： 验证模型是否正确加载
  3. API 格式检查： 验证响应格式是否正确
  4. OUTPUT 标记检查： 验证能否提取 OUTPUT 标记内容

⚠️ 常见问题

  • 超时 (504)： API 服务未启动或响应缓慢
  • 无法连接 (503)： API 地址或端口错误
  • JSON 解析错误 (400)： API 返回格式不正确
  • 响应结构错误： API 版本不兼容
